How it works

1. SELECT FILE

Drag a file in or browse. Size and basic validity are checked first.

2. ANALYZE LOCALLY

Bytes are read with the File and ArrayBuffer APIs. SHA-256 comes from Web Crypto.

3. CALCULATE RISK SCORE

Each matching indicator adds fixed points, capped at 100.

4. DISPLAY REPORT

Findings are split into detected, not detected and unsupported checks.

Scoring rules (illustrative)

Labels: 0-14 Low observed risk, 15-39 Caution, 40-69 Suspicious, 70-100 High risk.

Privacy

Files are processed in your browser and are not uploaded by this application. There are no analytics, external APIs, cloud scanning or file transfers. Scan history lives in memory only and disappears when you close or reload the tab.

What this cannot do

This is an educational prototype, not an antivirus engine. The score is a heuristic, not a probability, and a low score does not guarantee a file is safe. It does not unpack archives, decompress macro code, parse executable import tables, match malware signatures, run files in a sandbox or look up reputation online, because those need heavier tooling or a backend. Files are never executed.
